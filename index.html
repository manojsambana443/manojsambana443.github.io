# about

I work as a DevOps and Cloud Engineer, currently at LTIMindtree, building and operating cloud infrastructure that keeps production systems stable and teams shipping without friction. Over the past two years I've worked hands-on across AWS and Azure, provisioning infrastructure with Terraform, running containerized workloads on Kubernetes, and building CI/CD pipelines that teams actually rely on day to day.

# reliability

A big part of the job has been keeping systems reliable, not just running. I set up monitoring and observability using Prometheus, Grafana, and CloudWatch, and have been steadily moving toward SRE practices — defining SLIs and SLOs, tracking MTTR, and handling on-call rotations through PagerDuty with proper RCAs and runbooks.

# beyond the day job

I built a full Azure project (AKS, Terraform, Azure DevOps CI/CD, serverless processing, monitoring) to go deeper on Azure specifically, and a GCP project to get hands-on with Terraform and Ansible on Google Cloud — both linked below with the actual code, not just a description.
